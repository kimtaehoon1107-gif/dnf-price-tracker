# 유랑악단 패키지·주또주 계산 기준

공식 규칙 확인일: 2026-09-18. [구매 조건·아이템 제한](https://df.nexon.com/community/news/seriashop/656), [회차별 보상·프리미엄 코인샵](https://df.nexon.com/pg/forestbandpkg).

- 세라샵 정가 39,200세라. 세라샵 수령·선물 기준이며 경매장 패키지 구입에는 주또주가 붙지 않습니다. 선물 보상은 구매자에게 지급됩니다. 판매 종료 2026-11-05 06:00 KST 이후에는 과거 규칙 시뮬레이션 안내를 표시합니다.
- 1회차는 부화된 대상 크리쳐에 사용하는 첫 구매 변경권, 2~10회차는 공식 귀속 보상입니다. 기존 구매 수를 초과하고 최종 구매 수 이하인 회차만 포함합니다.
- 누적 코인은 1~10회차에서 각각 0·1·3·5·7·9·11·14·17·20개, 11회차 이후 매회 1개입니다. 새 코인 = 최종 누적 − 기존 누적입니다.
- 코인 교환은 열대야 오라(8코인, 계정당 5회)를 목표 수량까지 먼저 배정하고, 선택하면 나머지를 실반 멜로디 카드(2코인, 계정당 50회)로 최대한 교환합니다. 기존 교환 사용량을 빼고, 부족한 코인·초과 한도는 입력 오류로 표시합니다. 기타 코인샵 상품은 포함하지 않습니다.
- 기존 코인만으로 가능한 교환과 새 코인을 합산한 교환에 같은 목표·순서를 적용합니다. 두 경우의 카드 수량 차이만 판매 회수액에 넣고, 오라 수량 차이만 새 개인 사용 가치로 평가합니다. 오라를 추가 확보하며 기존에 팔 수 있었던 카드를 포기하면 카드 회수액 차이는 음수일 수 있습니다. 남는 코인은 가치 합계에 넣지 않고 잔여 수량으로 표시합니다.
- 패키지 그대로 판매와 구성 상자 판매는 상호 배타적입니다. 구성 상자를 골랐으면 각 종류에서 보관할 수량을 제외합니다. 기본 판매 회수액 = Σ(판매 수량 × 단가 × (1 − 수수료)). 전체 추가 판매 회수액 = 기본 판매 회수액 + 코인 카드 교환 증가분의 수수료 반영액입니다.
- 단가는 일반 아이템의 최근 24시간 수량가중평균입니다. 사용자 직접 입력이 우선이며 입력을 비우면 관측값으로 돌아갑니다. 판매 수량이 있는 물건의 가격이 없으면 전체 합계는 대기 상태입니다. 관측 시세 요약은 직접 입력과 별도로 유지합니다.
- 모든 귀속 보상의 사용 가치는 직접 입력하며 판매액에 합산하지 않습니다. 거래형 참고 가격은 거래·사용 제한이 다른 귀속형의 확정 가격이 아닙니다. 첫 구매 변경권은 변경 후 크리쳐 사용 가치에서 투입 크리쳐·재료 비용을 뺍니다. 이미 보유한 크리쳐도 대체 가치를 고려하도록 안내합니다. 입력하지 않은 보상은 가치가 없다고 판정하지 않고 합산에서 제외합니다.
- 추가 지출은 추가 구매 수 × 개당 세라 비용입니다. 사용자가 1,000세라당 골드 기준을 입력한 경우에만 골드로 환산해 판매 회수액과의 차이를 보여 줍니다. 귀속 보상의 개인 평가는 이 부담액에서 자동 차감하지 않습니다.
- 입력은 현재 페이지 메모리에만 유지하며 DB·서버로 전송하지 않습니다. 기존 수집 데이터로 계산하므로 새 수집 항목·DB 테이블을 추가하지 않습니다. 계산기 입력 합계 1,000개 제한은 UI 입력 범위이며 게임의 구매 제한을 뜻하지 않습니다.

`npm test`에서 구매 경계, 7→9회차, 첫 구매, 11회차 이후, 코인 잔여·한도·기존 자산 중복, 귀속 평가 분리, 누락 단가, 0개·잘못된 입력을 검증합니다.
