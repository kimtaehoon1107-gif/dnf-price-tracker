# 6시간 상승·보합·하락 예측 실험

**레전더리 소울 결정에는 시간대 방향의 후속 검증 가치가 있다. 카드 P10에서는 시간대 모델이 항상 보합 기준을 이기지 못했다.** 기존 자료에 대한 후향적 롤링 평가이며 새로운 날짜에 미리 발행한 예측 성과가 아니다.

## 범위

[고정 규칙](block-direction-protocol-2026-10-02.md)에 따라 KST 06·12·18·00시에 다음 6시간 평균 가격을 직전 6시간 평균과 비교했다. −0.5% 미만 하락, ±0.5% 이내 보합, +0.5% 초과 상승이다. 이 기준은 수익·수수료 기준이 아닌 작은 움직임을 구분하는 분석 기준이다.

당일 06시에 하루 전체를 고정 예측하는 이전 실험과 달리 **6시간마다 그때까지 완료된 자료로 다음 구간을 새로 예측**한다. 각 구간 관측 4시간 이상을 요구하고 보간하지 않는다. 과거 학습 조건을 채워야 하므로 앞선 19일 반복성 집계와 표본이 다르다. 이전에는 낮→새벽을 비교했지만 이번 새벽 예측은 직전 **저녁→새벽** 변화다.

입력은 2026-10-01 18:00 KST 기준 검증 보관본이다. 10월 2일 실시간 자료를 추가하지 않았다. 일반 품목은 시간봉 VWAP과 매물이 함께 관측된 시간에 조건부이며, 카드 P10은 관측 호가 지표다. 체결 시각 기준 과거 재구성으로, 당시 백필·도착 지연까지 재현하지는 않는다.

## 전체 적중률

| 모델 | 카드 P10: 54구간·15게임일 | 소울 결정: 58구간·16게임일 |
|---|---:|---:|
| 항상 보합 | 57.4% | 1.7% |
| 항상 하락 | 25.9% | 51.7% |
| 항상 상승 | 16.7% | 46.6% |
| 과거 전체 최빈 방향 | 57.4% | 44.8% |
| **과거 시간대별 방향** | **53.7% (29/54)** | **77.6% (45/58)** |
| 직전 구간 방향 유지 | 59.3% | 48.3% |

시간대 모델은 과거 같은 시간대의 방향 횟수에 전체 방향 빈도 4개 분량을 더해 최빈 방향을 선택한다. 모든 계산은 해당 발행 시점 이전 완료 구간만 사용한다. 수치는 독립적인 54일·58일 평가가 아니다.

카드에서 직전 방향 유지의 보합 기준 대비 차이는 **단 한 구간**이다. 이를 안정적인 우위로 해석하지 않는다. 소울 결정의 시간대 모델은 강한 후속 검증 후보지만, 해당 구간에서 늘 같은 방향을 선택해 얻은 성과다. 날짜별 특수 상황까지 예측한 복잡한 모델이 아니다.

### 클래스별 성과

- 카드 실측 하락/보합/상승 = 14/31/9. 시간대 모델의 관측 클래스 평균 재현율은 50.8%, 항상 보합은 33.3%다. 소수인 상승·하락을 잡는 장점과 보합을 틀리는 비용이 공존한다. 전체 적중률에서는 우세하지 않다.
- 소울 결정 실측 하락/보합/상승 = 30/1/27. 시간대 모델은 하락 24/30, 보합 0/1, 상승 21/27을 맞혔다. 평균 재현율은 52.6%다. **77.6%가 세 방향을 고르게 잘 맞힌다는 뜻은 아니다.**

아래 하락/보합/상승 건수는 각 예측 구간 평균을 직전 구간 평균과 비교한 실제 분포다.

| 대상 | 구간 | 실측 하락/보합/상승 | 시간대 모델 적중률 |
|---|---|---:|---:|
| 카드 P10 | 06~12 | 4/8/1 | 61.5% |

| 소울 결정 | 18~24 | 3/0/11 | 78.6% |

소울 결정은 직전 새벽 대비 오전 하락, 오전 대비 낮 상승, 낮 대비 저녁 상승, 저녁 대비 새벽 하락의 후보 형태다. 매일 반드시 발생한다는 뜻은 아니다. 카드의 낮 하락은 존재하지만 0.5% 기준에서는 보합도 많다. 새벽 회복을 너무 자주 예상하는 부분은 취약하다.

## 기준과 결측에 따른 민감도

| 보합 범위 | 카드 시간대 / 항상 보합 | 소울 시간대 / 항상 하락 |
|---|---:|---:|
| ±0.25% | 46.3% / 51.9% | 75.9% / 51.7% |
| **±0.5% (주 기준)** | **53.7% / 57.4%** | **77.6% / 51.7%** |
| ±1% | 61.1% / 68.5% | 69.0% / 44.8% |

보합 범위를 넓히면 정답 분포 자체가 바뀌므로 다른 행의 적중률 상승을 모델 개선으로 해석하지 않는다. 같은 행의 기준선과 비교해야 한다. 좋은 결과가 나온 임계값으로 교체하지 않았다.

직전·목표 구간 모두 6시간 완전 관측인 사례만 보면 카드 47구간에서 시간대 51.1% / 항상 보합 61.7%, 소울 결정 54구간에서 시간대 79.6% / 항상 하락 53.7%였다.

## 상태와 재현

이는 **과거 자료에서 평가한 방향 예측 후보**다. 운영 사이트에 상승·보합·하락 예측을 게시하거나 자동 예측 발행을 시작하지 않았다. 요일×시간대는 표본이 적어 추가하지 않았다. 목요일 결측, 짧은 기간, 같은 날짜 내 상관관계, API 관측 한계가 남는다. 새 기간의 예측을 미리 저장해 검증하기 전에는 실시간 정확도나 상승 확률로 표시하지 않는다.

```sh
node scripts/test-block-direction-study.ts
node scripts/block-direction-study.ts
npm test
```

입력은 `data/intraday-study/activity-input.json`이며 [전체 예측·정답·혼동행렬·제외 사유](evidence/block-direction-20261002.json)에 입력 해시와 기준 시각을 보존했다. 미래 가격 변경에 대한 예측 불변성, 목표 결측에도 예측 유지, 진행 중인 구간 제외, 분류 경계값, 게임 날짜 매핑 테스트를 통과했다.
