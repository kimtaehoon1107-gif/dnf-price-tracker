# 시세 이야기

홈의 접힌 버튼에서 여는 공용 댓글 패널이다. `@아이템명` 자동완성으로 최대 5개 품목을 연결하고, 전체/현재 아이템 필터와 답글을 제공한다. 공백 없는 `@에픽소울` 검색도 된다.

- 닉네임 20자, 본문 200자. 회원가입 없이 작성하며 닉네임은 신원을 보증하지 않는다.
- 작성 전 브라우저에 임의 관리키를 저장하고 서버에는 bcrypt 해시만 저장한다. 같은 브라우저에서 본인 글을 삭제한다. 브라우저 저장소를 지우거나 기기를 바꾸면 삭제권을 복구할 수 없으며 관리자 숨김을 요청해야 한다.
- 삭제 시 본문·닉네임·태그를 지우고 답글은 보존한다. 관리자 숨김은 다시 공개할 수 있다.
- 기존 피드백 관리자 비밀번호로 숨김/공개한다. 관리자 비밀번호는 메모리에만 두며 15분 후 만료한다.
- 열린 패널은 30초, 접힌 패널은 60초 간격으로 갱신한다. 숨겨진 브라우저 탭과 과거 글을 읽는 동안에는 자동 조회를 멈춘다. 실시간 소켓 방식은 아니다.
- 작성은 IP 기반 해시당 분당 6회·시간당 60회, 삭제 인증은 글당 15분 10회로 제한한다. 게시판과 공통 전체 요청 상한도 적용한다.
- 요청 UUID로 재전송을 중복 방지한다. 응답을 못 받으면 같은 내용으로 재시도한다.

## 배포

1. B 프로젝트에 `sql/chat.sql` 적용 (`sql/feedback.sql`이 먼저 필요).
2. 기존 `feedback` Edge Function에 `index.ts`와 `chat.ts`를 함께 배포. 기존 `verify_jwt=false` 설정을 유지한다. 테이블 직접 조회/쓰기 권한은 없으며 Edge Function만 RPC를 호출한다.
3. 사이트 빌드가 `web/chat.js`를 복사하고 `index.html`이 이를 불러온다.

2026-10-06 B 스키마와 Edge Function 배포 완료. 운영 `chat-list`와 기존 `list` 모두 HTTP 200 확인. 운영 댓글에 테스트 글은 쓰지 않았다.

## 검증

`npm test`는 입력 검증·횟수 제한·RPC 분리를 검사한다. `node --env-file=.env scripts/test-chat-db.ts`는 독립 이름의 스키마를 트랜잭션 안에 만들고 소유권·관리 권한·중복 요청·답글·태그 필터·삭제를 검증한 뒤 롤백한다.

`node --env-file=.env scripts/preview-chat.ts`는 4203 포트에서 같은 격리 DB 방식의 UI 테스트를 제공한다. 종료하면 테스트 댓글이 롤백된다. 장시간 켜 두지 않는다.
