# 요일 정보 추가 비교 규칙

- 앞선 구간 선택 결과를 고정한다. 구간을 다시 고르지 않는다. 입력 해시와 시간대 예측·정답이 이전 결과와 동일한지 대조한다.
- 주 비교는 시간대 모델 대 요일×시간대 모델이다. 참고로 전체 최빈 방향 대 요일 모델도 보고한다. ±0.5% 분류와 관측 기준은 유지한다.
- 요일은 06시 시작 게임 하루에 붙인다. 화요일 00~06시는 월요일 게임 하루다.
- 요일 모델: 같은 요일의 과거 방향 횟수 + 전체 방향 비율 8개 분량. 요일×시간대: 같은 요일·시간대의 과거 방향 횟수 + 기존 시간대 모델 방향 비율 8개 분량. 보정 강도 8은 튜닝하지 않는다.
- 해당 셀의 과거 관측 날짜가 2일 미만이면 각각 전체 최빈/시간대 모델로 돌아간다. 평가 사례를 삭제하지 않으며 실제 요일 정보를 사용한 사례 수와 예측을 바꾼 횟수를 표시한다.
- 발행 시각까지 끝난 구간만 학습한다. 평가 기간 09-25 06시~10-01 06시(6게임일)는 고정하며 매 발행마다 과거 자료로 순차 갱신한다. 목요일 시작 날짜는 이 기간에 없으므로 목요일 예측 성능을 주장하지 않는다.
- 동일 정답에서 전체 정확도·균형 정확도·게임일 동일 가중 정확도와 변경 후 맞힌/틀린 횟수를 보고한다. 요일별 정답 분포도 남기지만 각 요일이 한 번뿐인 평가로 반복 효과를 확정하지 않는다.
- 기존 결과를 본 뒤 만든 후향적 추가 실험이다. 독립적인 새 기간 검증·통계적 유의성·매매 성과가 아니다. 개별 카드 수십 종 비교의 우연한 개선 가능성을 밝힌다.
