# 아이템 비교 · 2026-10-02

- `index.html#compare` 또는 개별 상세의 비교 링크로 진입한다. 일반 아이템과 카드는 섞지 않는다.
- 일반 아이템은 기존 정적 `distribution.daily`의 수량 가중 중앙값, 카드는 0업/맥스업의 `daily.vwap`(일평균 최저호가)을 사용한다. 맥스업 이력이 없으면 0업으로 대체하지 않는다.
- 비교 기간은 7/30개 완료일 또는 전체다. 두 소스 중 이른 집계 시각을 기준으로 오늘을 제외하고, 두 종목에 모두 유효한 가격이 있는 공통 시작·종료일을 표시한다. 공통 관측일이 2일 미만이면 비교를 보류한다.
- 시작 100 지수는 두 종목의 같은 시작일 가격으로 각각 정규화한다. 실제 골드 보기로 전환할 수 있다. 결측·불완전 원본·5건 미만 체결은 선을 연결하지 않는다.
- 상세 기간 변화는 선택한 그래프 안의 첫/마지막 유효 완료 관측일 기준이며 실제 계산 날짜를 명시한다.
- 상세 및 비교 그래프의 목요일 표시는 KST 달력 날짜를 사용한다. 실제 점검/이벤트 발생을 의미하지 않는다. 좁은 화면의 긴 기간에서는 44px 이상의 버튼 간격을 확보한다.
- 주또주 가치 계산기와 전용 입력/계산 코드를 제거했다. 패키지 해체 마진과 연구용 패키지 이벤트 관측, 카드 강화 기대비용은 유지한다.
- 운영 DB, 수집 스케줄, 데이터 추출은 변경하지 않는다. 비교는 이미 공개된 종목별 JSON 두 개를 읽고 화면 내 선택 변경 시 재사용한다.

검증: `npm test`, 공개 데이터 기반 로컬 일반/카드 비교, 7일/30일·골드/지수 전환, 목요일 선택, 모바일 390px, 주또주 제거 및 해체 마진 유지.
