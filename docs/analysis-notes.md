README에서 옮긴 상세 기록입니다. 수치는 해당 시점의 값이며, 최신 결과는 사이트의 [분석](https://kimtaehoon1107-gif.github.io/dnf-price-tracker/analysis.html)·[실험](https://kimtaehoon1107-gif.github.io/dnf-price-tracker/research.html) 페이지가 매시간 다시 계산합니다.

## 표시 가격과 평균 트렌드

[시간대·요일 평균 트렌드](https://kimtaehoon1107-gif.github.io/dnf-price-tracker/seasonal.html)는 매시간 통합 자료로 갱신됩니다. 최근 최대 8주의 자정/6시 공통 완료일을 사용하고, 품목군 구성품을 동일 비중으로 평균합니다. 가격·관측 매물 건수, 날짜별 평균·중앙값, 표본 수를 구분하며 통계적 유의성이나 예측력을 주장하지 않습니다.

표시용 체결 가격은 **KST 날짜별 원본 체결 단가 중앙값의 1/10 미만·10배 초과를 제외**하고 다시 계산합니다. 중앙값은 거래 건별이며, 이후 평균은 수량 가중입니다. 원본과 이미 발행된 연구 기록은 보존합니다. 카드 호가는 이 필터의 대상이 아닙니다. [정제 규칙·21일 모델 평가](display-cleaning-and-arima-2026-10-08.md)

## 데이터로 점검한 것

- **가격 변화에 단기 반전·지속 신호가 있는지 검정합니다.** 종목별 가장 긴 연속 완료 시간봉 구간(최소 30봉)에 VR(2) 검정을 적용합니다. 겹치는 수익률의 편향을 보정하고, 이분산에 견고한 표준오차와 Holm 다중 검정 보정을 적용합니다. 장기 평균회귀와 실제 매수 전략의 유용성은 미검증이며, 체결 수 그룹 비교만으로 관측 잡음을 배제하지 않습니다.
- **예측 성능은 날짜별 롤링 평가로 확인합니다.** 평가 당일을 제외한 자료로 요일 계수와 추세를 다시 추정하고, 마지막 완료 일봉의 VWAP을 유지하는 naive와 1일·7일 뒤 오차를 비교합니다. 백필을 포함한 체결 시각 기준 평가이며 당시 수집기가 보유했던 자료의 재현은 아닙니다. 성능 차이의 원인을 평균회귀라고 단정하지 않습니다.
- **일반 아이템 상세에는 예측을 그리지 않습니다 — 예외 3종이 있습니다.** 모델 오차가 naive보다 컸고, 방향 없이 폭만 정하는 과거 변동폭 기반 참고 범위(마지막 완료일 가격 ± 하루 변동폭 80분위수 × √일수)도 결과를 보기 전에 공식을 고정해 같은 롤링 평가로 재구성했지만 실제 포함률이 목표 80%에 못 미쳐 분석 페이지에만 기록합니다. 예외로 에픽·레전더리 소울 결정과 닳아버린 순례의 증표의 상세 차트에는 요일 추가 ARIMA의 7일 예측선을 **‘실험 예측 · 검증 중’** 으로 그립니다. 이 3종은 결과를 알고 난 뒤 고른 품목이고 과거 재현의 7일 뒤 평가는 품목마다 1건뿐이며, 발행 당시 값을 저장해 나중의 실제 가격과 비교하는 평가는 아직 이 예측에 연결되지 않았습니다. 불확실성 범위도 표시하지 않습니다.
- **유랑악단 패키지 탭에서 해체 마진을 계산합니다.** 패키지와 구성품 5종의 최근 24시간 VWAP이 모두 있을 때 수수료 3%를 반영합니다. 관측 가격 기준일 뿐 실제 판매 가능성이나 확률형 개봉 수익을 보장하지 않으며, 결측은 0으로 대체하지 않습니다. 2026-09에 있던 주또주 가치 계산기는 #31에서 제거했고 [당시 계산 기준](package-calculator.md)은 기록으로만 남겼습니다.
- **요일별 가격 트렌드를 품목군별로 비교합니다.** 메인 품목 탭과 카드 딜러·버퍼 선택을 반영해 월~일 가격 수준과 전날 대비 변화율을 보여 줍니다. 일반 체결가·카드 0업·맥스업 호가는 분리합니다. 일반 아이템은 하루 체결 5건, 카드는 하루 호가 18시간 이상을 유효 관측으로 삼고 월~일 완료 주 4주 이상인 종목에 같은 비중을 줍니다. 가격 수준은 종목별 주평균 100 기준이며, 전날이 결측이면 변화율을 계산하지 않습니다. 조건을 채운 종목이 없는 품목군에서는 메인 패널을 숨기고, 준비 현황은 분석 페이지 한계 절에 공개합니다.
- **요일 효과의 통계 검정과 아이템 유형 군집은 보류했습니다.** 요일별 관측 패턴과 유의성 판정은 다릅니다. 4주는 표시 기준이며 검정력을 보장하지 않고, 패치·이벤트 영향을 제거한 결과도 아닙니다. 목요일은 비교를 위한 강조이며 메인에서 `p<0.05`·`현재 비유의` 판정은 사용하지 않습니다.

**2026-09-19 00:55 KST 빌드의 검증 예:** 체결가 분석 후보 38종 중 19종이 분산비 검정 조건을 충족했고, Holm 보정 후 반전 신호 5종·지속 신호 0종이었습니다. 1일 뒤 예측은 35종·139건에서 모델 MAPE 5.29%, naive 3.90%, 7일 뒤는 9종·48건에서 12.14%, 6.43%로 모델의 오차가 더 컸습니다. 참고 범위의 실제 포함률은 1일 73.4%, 7일 60.4%였습니다. 이 수치는 해당 시점의 기록이며, 최신 결과는 매시간 재계산됩니다.

**2026-09-16 요일 보정 비교 실험:** 동일한 과거 평가 사례에서 마지막 가격 유지 / 추세만 / 추세+요일의 MAPE는 1일 뒤 **4.233% / 6.412% / 6.469%**(11종·72건), 7일 뒤 **8.396% / 12.528% / 12.245%**(6종·27건)였습니다. 요일 추가의 영향은 예측 거리·종목별로 달랐고 두 추세 모델 모두 전체 평균에서 가격 유지보다 오차가 컸습니다. 통계적 유의성이나 미래 성능을 입증한 결과는 아닙니다. `npm run experiment:forecast`로 재실행할 수 있으며, [평가 조건·종목별 결과·제외 종목](forecast-comparison-2026-09-16.md)을 기록했습니다.

## 레전더리·종류별 사전 예측

[레전더리 화면](https://kimtaehoon1107-gif.github.io/dnf-price-tracker/index.html#legendary-card)에서 일평균 최저호가와 P10을 별도로 보고, [실험 화면](https://kimtaehoon1107-gif.github.io/dnf-price-tracker/research.html)에서 10개 고정 구성 지수와 구성 아이템별 흐름을 비교합니다. 화면 정리를 위해 기본 목록에는 구성 4종 이상인 7개만 두고, 1~3종 구성은 '소수 구성도 보기'로 엽니다. 체결 VWAP과 카드 단계별 호가는 분리합니다.

2026-09-16부터 매일 발행한 입력·예측을 보존해 최근 가격 유지·지난주 같은 요일·추세+요일의 실제 후속 오차를 비교합니다. 요일 모델은 각 요일 관측 4회 이상일 때 참여하며, 미래 대상일은 평가 대기로 표시합니다. [패키지 분석](https://kimtaehoon1107-gif.github.io/dnf-price-tracker/research.html#package)은 고정된 전후 7일의 가격·구성품·해체 마진·관측 수량을 비교합니다. 표본 조건·사전 평가·결측 처리·실행 방법은 [방법 문서](market-research.md)에 정리했습니다.

2026-09-20부터 카드의 시간별 마지막 무매물 상태를 반영한 v2 집계로 새 예측을 발행합니다. 기존 v1 예측·평가 기록은 보존하며 남은 평가도 원래 기준으로 마감합니다. 레전더리 165종은 카드별 최저호가·매물 건수·정상/무매물/실패 상태를 실행별 요약으로 저장하고, 부분 조회 실패를 전체 최저가로 발표하지 않습니다.
