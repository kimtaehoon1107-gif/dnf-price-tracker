# D-NOTE 시간봉 탐색 분석 규칙

작성일: 2026-11-03. 사건 발생 후 설계한 탐색 분석이며 사전 등록이나 확증 검정이 아니다. 결과를 계산하기 전에 이 파일을 작성했다.

- 사건 기준: 공식 공지 https://df.nexon.com/community/news/notice/2928724 의 예정 방송 시작 2026-10-27 19:00 KST. 실제 첫 발언 시각을 확인한 것은 아니다. 20:00 퍼스트 서버 개방은 별도 동시 사건이다.
- 대상: 공개 summary에서 price_basis=trade인 모든 품목. 호가 기준 카드 34종은 체결 가격과 섞지 않고 제외한다. 대상을 결과로 선별하지 않는다.
- 입력: 담당 B/C의 기존 candles_1h 원본 시간봉. 2026-09-28 19:00~10-28 19:00 KST만 읽는다. 각 DB repeatable-read/read-only 트랜잭션, 담당 품목 경계 확인, 입력 원문·해시·집계 시각·코드 기준 커밋 보존. 과거 재수집·DB 쓰기·예측/패키지 연구 규칙 변경 없음.
- 기본 비교: 방송 직전 6시간 [13:00,19:00)의 수량 가중 평균 체결가와 직후 1·6·24시간의 동일 평균을 비교한다. 거래량은 시간당 관측 수량의 비율이다. 모든 시간봉에 양의 가격·수량·건수가 있어야 한다. 결측을 0이나 직전 가격으로 채우지 않는다. 시간봉 존재가 API의 거래 전수 포착을 보증하지는 않는다.
- 1시간 창 [19:00,20:00)은 서버 개방 전 구간이다. 6·24시간은 방송과 서버 개방을 함께 포함한다. 각각 탐색 결과이며 주된 요약은 6시간 창이다.
- 평소 변동 참고: 사건 전 28일의 매일 19시를 가상 사건으로 두고 같은 전후 계산을 한다. 해당 창의 끝이 공지 게시 10-23 15:00 KST 이후이면 제외한다. 최소 20개의 유효 가상 사건을 요구한다. 실제 변화에서 가상 사건 변화의 중앙값을 뺀 값을 초과 변화(퍼센트포인트)로 표시한다.
- 참고 범위: 가상 사건 변화의 경험적 5~95백분위(선형 보간). 이는 평소 움직임의 기술적 범위이며 효과의 신뢰구간이나 유의성 검정이 아니다. 범위 밖은 '평소 범위 밖(탐색)', 안은 '뚜렷한 이례성 증거 부족', 표본 부족은 '자료 부족'. 38종·여러 창을 함께 살펴보므로 일부 범위 이탈은 우연히 생길 수 있다. 이 비율을 p값으로 부르지 않는다.
- 민감도: 기준선을 직전 24시간으로 바꿔 같은 계산; 목요일 전후 창을 제외한 참고군; 화요일 19시만의 참고군(최소 4개, 기술적 비교 전용). 기본 참고군에도 다른 사건·추세가 섞이며 미발생 반사실이 아니다.
- 경로: -24~+24시간의 실제 시간봉을 직전 6시간 평균=100으로 표시한다. 결측은 공백으로 보존한다.
- 결론: 이례적 관측과 인과효과를 구분한다. '유의하지 않음'을 '영향 없음'으로 바꾸지 않는다. 운영 화면에 자동 반영하거나 정기 실행하지 않는 일회성 분석이다.
