# 6시간 구간 상승·보합·하락 실험 규칙

기존 패턴을 관찰한 자료를 다시 사용하는 후향적 탐색이다. 새 기간의 사전 발행 검증이나 독립 표본 성과라고 주장하지 않는다.

- 대상: 카드 P10·레전더리 소울 결정. 기존 검증 보관 입력을 사용한다.
- KST 06·12·18·00시에 직전 완료 6시간 평균 대비 다음 6시간 평균의 방향을 예측한다. 00시 구간은 전날 06시에 시작한 게임 하루에 속한다.
- 변화율이 −0.5% 미만이면 하락, +0.5% 초과이면 상승, 그 사이와 경계는 보합이다. 0.25%·1%는 민감도만 보고하며 더 잘 나온 임계값으로 교체하지 않는다. 이 범위는 거래 수수료나 수익 기준이 아니다.
- 6시간당 최소 4시간 관측, 보간 없음. 구간 종료 전에는 평균을 학습·정답에 사용하지 않는다. 가격은 시간별 값의 산술평균이며 일반 품목의 일간 VWAP과 다르다.
- 과거 최대 28일, 완료 변화 관측 28개 이상·기간 7일 이상·동일 시간대 4개 이상부터 발행한다. 모델 간 동일 비교를 위해 직전 두 구간이 모두 필요하다.
- 비교: 항상 보합·항상 하락·항상 상승·과거 전체 최빈 방향·시간대별 방향 빈도·직전 변화 방향 유지. 빈도가 같으면 보합, 하락, 상승 순으로 선택한다.
- 시간대 모델은 같은 시간대의 각 방향 횟수에 과거 전체 방향 비율×4를 더해 최빈 방향을 선택한다. 작은 표본의 극단적 판단을 줄이는 고정 보정이며 4를 튜닝하지 않는다. 빈도를 검증된 확률로 표시하지 않는다.
- 학습 정답은 발행 시각까지 끝난 구간만 사용한다. 미래 결측 때문에 발행을 취소하지 않고 평가 가능 여부를 별도로 기록한다.
- 전체·시간대별 정확도, 클래스별 표본·혼동행렬, 관측된 클래스의 평균 재현율을 보고한다. 같은 날 4구간을 독립적인 4일로 보지 않는다. 6시간 완전 관측 사례도 별도 비교한다.
- 요일×시간대 모델은 표본이 작아 이번에 추가하지 않는다. 06시에 하루 전체를 발행하는 모델도 이번 범위에 넣지 않는다. 우선 6시간마다 다음 구간만 예측한다.
- 결과와 코드를 저장하되 운영 예측 발행이나 공개 사이트 표시는 자동으로 시작하지 않는다.
