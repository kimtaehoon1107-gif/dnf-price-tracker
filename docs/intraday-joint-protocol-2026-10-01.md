# 오전→저녁 예측 공동 평가 규칙 (2026-10-01)

기존 시간대 그래프와 9월 자료를 이미 본 상태에서 작성한 **후향적 탐색 규칙**이다. 사전 등록이나 미사용 최종 시험으로 주장하지 않는다. 이번 실행 결과를 보기 전에 아래 비교를 고정하며, 새 날짜의 사전 발행 평가는 별도 과제다.

## 최근 연구에서 적용할 것

- [Chronos-2 (2025)](https://arxiv.org/abs/2510.15821): 다변량·외부 변수·관련 시계열을 함께 사용하는 방향. 여기서는 가격만/시간대 추가/매물 추가의 단계별 비교에 적용한다. Chronos-2 자체를 실행하거나 그 논문의 성능을 던파에 전이했다고 주장하지 않는다.
- [Berthelier 외, ICLR 2026 TSALM workshop](https://helios2.mi.parisdescartes.fr/~themisp/publications/tsalm26-covariateforecasting.pdf): 단순한 목표-외부 변수 관계에서도 모델별 성능이 다르며 강한 벤치마크 성적이 특정 변수 활용을 보장하지 않는다. 작은 통제 비교와 단순 기준선을 유지한다.
- [Briola 외, Deep Limit Order Book Forecasting (2024 preprint / 2025 journal)](https://arxiv.org/abs/2403.09267): 시장 구조와 평가 목적이 중요하며 높은 예측 성능과 실행 가능한 거래 신호는 다르다. 던파의 매도 매물 관측을 양방향 LOB/주문 흐름 불균형으로 간주하지 않는다.
- [Prata 외, LOB trend prediction benchmark (2024)](https://link.springer.com/article/10.1007/s10462-024-10715-4): 미래 평균 가격을 기준으로 상승/보합/하락을 정의하는 평가를 참고한다. 이 연구의 이벤트 단위 간격·임계값·주식 체결 가정을 그대로 쓰지는 않는다.
- [Linna 외 (2026-09 preprint)](https://arxiv.org/abs/2609.16930): 반사실적 주문 메시지를 이용한 시장 영향 연구. 우리는 주문 메시지와 반사실 검증 자료가 없어 인과적 시장 영향 추정은 적용하지 않는다.
- [Forecasting: Principles and Practice, time-series CV](https://otexts.com/fpp3/tscv.html): 평가 원점을 앞으로 이동하고 그때까지 관측 가능한 정답만 학습한다.

딥러닝을 새로 학습할 독립 날짜가 부족하고 전체 주문 흐름도 없다. 현재 자료에서는 해석 가능한 소규모 모델과 엄격한 시간 순서 비교를 먼저 실행한다. 최신 모델의 미실행을 성능 실패로 해석하지 않는다.

## 고정 목표와 입력

- 주 대상: 레전더리 미업글 P10. 보조: 소울 결정 6종·유랑악단 6종 각각. 서로 다른 품목의 날짜를 독립 반복으로 합산하지 않는다.
- 원점: **KST 08시 시간봉 종료(09:00)**. 목표: 당일 18·19·20시 관측 가격의 산술평균. 세 시간 모두 있어야 채점한다. 일반 품목의 목표는 시간봉 VWAP의 평균이며 저녁 전체 수량 가중 VWAP과 다르다.
- 원점 가격은 08시 가격이다. 방향은 목표/원점 − 1을 사용한다. 이전 연구의 06~08시 평균 대비 변화와 수치가 같을 필요가 없다.
- 과거 24시간 가격 변화, 현재~3시간 전 관측 매물 변화만 사용한다. P10은 건수, 일반 품목은 잔량이다. 저녁의 실제 매물은 예측 입력에 넣지 않는다.
- 모든 모델은 동일한 과거 가격·매물 입력이 있는 원점에서 비교한다. 미관측은 보간하거나 0으로 채우지 않는다. 일반 품목은 관측 체결이 있는 시간에 조건부다.

## 모델과 시간 순서

1. `hold`: 마지막 가격 유지.
2. `trend`: 24시간 로그 가격 변화 × 예측 거리/24를 입력으로 쓰는 직접 Ridge 회귀.
3. `clock`: trend + 미래/현재 시각의 24시간 sine/cosine 차이. 달력 시각은 미래에도 알려져 있다.
4. `stock`: clock + 최근 3시간 `log(1+매물)` 변화.
5. `yesterday`: 전날 같은 오전→저녁 가격 비율을 현재 오전 가격에 적용. 필요한 전날 관측이 있는 경우에만 보조 비교.

10·11·12시간 뒤 가격에 대한 로그 수익률 회귀를 각각 학습하고, 세 예측 가격을 산술평균한다. 과거 모든 시간대의 관측쌍으로 학습한다. 원점까지 정답 시간이 도달한 쌍만 사용하며 최근 최대 28일, 최소 120쌍·학습 원점 범위 7일을 요구한다. Ridge 벌점 1 고정, 절편 제외·입력 표준화는 매 원점 학습 자료만 사용한다. 조정 탐색 없이 그대로 실행한다.

## 함께 평가할 항목

- 가격: MAPE, 절대오차 중앙값, 오차 90분위수, 평균 예측 편향, hold 대비 날짜별 승리 수.
- 방향: 기본 보합 범위 ±0.5%, 보조 0%·±1%. 상승/보합/하락 혼동행렬, 적중률, 균형 적중률을 함께 보고한다.
- 방향 기준선: 항상 하락/보합/상승. 가격 기준선에 가짜 하락 가격을 부여하지 않는다.
- coverage: 전체 원점 날짜, 입력 부족, 학습 부족, 예측 생성, 미래 목표 결측, 채점 수를 구분한다. 미래 목표 결측을 보고 예측 생성 여부를 정하지 않는다.
- paired 비교: 같은 날짜의 stock−clock, clock−trend, 각 모델−hold 가격 오차 차이. KST 3일 달력 블록을 재표집하는 탐색적 95% 구간(2,000회·고정 시드)을 제공하되 독립 날짜가 적으므로 확증 p값으로 사용하지 않는다.
- 민감도: 목요일 평가일 제외, 원점·과거 입력·저녁 목표의 정상 수집 기록 확인 사례만 별도 채점. 주 모델과 예측값은 바꾸지 않는다. 이 조건은 학습 전기간 완전성을 보증하지 않는다.
- 가격 하락 추세·평균 패턴을 발견한 자료의 재사용, API 표본 상한, 백필을 포함한 역사 재구성, 작은 평가 일수의 한계를 결과 옆에 명시한다.

운영 수집·스키마·예측 표시를 변경하지 않는다. 입력은 앞선 검증된 보관 추출물을 재사용해 불필요한 DB/API 호출을 피한다.
