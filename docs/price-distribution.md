# 일반 아이템 가격 분포 화면

맨 위 OHLC 캔들을 수량 가중 중앙값의 점·직선과 구간별 주요 거래 가격대로 교체한다.
카드는 체결 단계 구분이 불가능하므로 기존 단계별 최저호가 화면을 유지한다.
상단 대표 가격(최근 60분 VWAP), 수집 주기, 운영 DB 스키마·보존 정책은 변경하지 않는다.

- 기본 최근 30일, 7일/전체 선택. 날짜 클릭 또는 선택기로 해당 KST 날짜의 시간별 자료를 연다.
- 회색 구간은 누적 체결 수량의 25%·75%에 처음 도달하는 가격이다. 건수 분위수나 예측 구간이 아니다.
- 체결 5건 미만은 점만 표시한다. 이는 보수적인 표시 기준이며 통계적 신뢰성 판정이 아니다.
- 체결 없는 달력 구간은 선을 끊는다. 무거래/수집 실패를 확정할 수 없어 '체결 관측 없음'으로 표시한다.
- 집계가 있으나 원본이 불완전하면 분위수는 NULL로 두고 '분포 자료 없음'을 표시한다. 평균값으로 대체하지 않는다.
- 진행 중인 날짜·시간은 '수집 중'. 미래 구간은 시간별 화면에서 제외한다.
- 원본 최고·최저가와 VWAP는 접힌 상세에서 확인한다. 극단값을 삭제하거나 수정하지 않는다.

## 데이터 경로

`unifyMarket`가 R2와 현재 캐시를 합친 임시 PostgreSQL에서, 원본 조회 창을 정리하기 **전에**
`buildPriceDistribution`을 실행한다. 기존 자연키 중복 제거와 집계 ID 경계 안의 원본만 사용한다.
가격별 수량을 합쳐 일·시간 분위수를 각각 계산한다. 일별 값은 시간별 중앙값의 평균이 아니다.
원본의 건수·수량·최고·최저가를 기존 시간봉/일별 집계와 대조한 구간만 분위수를 내보낸다.
추가 운영 DB 조회나 R2 객체 형식 변경 없이 기존 복원 자료를 재사용한다.

## 검사

`npm test`: KST 경계, 결측 연결 차단, 소표본과 원본 없음 구분, 진행 중 시간.
`scripts/test-price-distribution-db.ts`: 임시 DB에서 수량 가중 분위수, 동일키 복수 체결,
집계 ID 경계, 카드 제외, 원본 누락과 극단값 보존.
기존 R2 실자료 사이트 병합 검사는 신규 분포 출력까지 전환 전후 대조한다.
